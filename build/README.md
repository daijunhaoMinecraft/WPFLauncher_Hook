# Build Output

`Mcl.Core.dll` in this directory is generated by the
`Build Mcl.Core` GitHub Actions workflow and committed automatically.

Do not edit or build this file locally. The workflow:

- reads launcher and third-party dependencies from the private
  `WPFLauncher_Hook_Build` repository;
- builds `Mcl.Core/Mcl.Core.csproj` for `.NET Framework 4.8`, `Release`, `x86`;
- verifies the private dependency hashes;
- updates only `build/Mcl.Core.dll` in the public repository.

The proprietary launcher and dependency binaries are never committed here.
