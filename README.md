# Build Artifacts

This orphan branch contains generated `Mcl.Core.dll` builds for the public
`WPFLauncher_Hook` project.

- Do not merge this branch into `main`.
- Do not commit source code, private dependencies, or account data here.
- `build/Mcl.Core.dll` is generated by GitHub Actions.
- Artifact commits reuse the triggering source commit message and include an
  `MCL-SOURCE-COMMIT` marker.
- `HookUpdateManager` reads this branch through the GitHub Contents API.

## Optional Runtime Attachments

The following files are optional and can be placed next to the launcher
executable:

- `build/wintun.dll`: enables the virtual network mode.
- `build/ocr.dll`, `build/OcrProxy.dll`, and `build/WmCode.dll`: enable automatic
  captcha recognition. These three files must always be installed together;
  omitting any of them can break captcha recognition.
